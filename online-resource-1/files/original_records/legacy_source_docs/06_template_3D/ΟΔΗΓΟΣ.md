# Πρότυπο προσβάσιμης 3D σελίδας (a11y3d)

Αντικαθιστά τα παλιά πρότυπα «TEMPLATE 3D INTER» του Google Web Designer. Από ένα GLB και έναν **σημασιολογικό χάρτη** φτιάχνει τρία πράγματα μαζί: τη διαδραστική σελίδα, τη στατική εκδοχή χωρίς JavaScript και τη σελίδα fallback του EPUB.

## Τι κερδίζει ο μαθητής

- Λίστα με ονομασμένα τμήματα: εμφάνιση, απόκρυψη και επισήμανση με ανάγνωση της περιγραφής.
- Περιστροφή με τα βέλη, όψεις με τα 1, 2, 3, περιγραφή της όψης με το D.
- Ανακοινώσεις για αναγνώστη οθόνης για ό,τι αλλάζει.
- Δύο παλέτες, αρχική και ελεγμένη για δυσχρωματοψία. Η ελεγμένη έχει μοτίβα και περιγράμματα, ώστε το χρώμα να μην είναι ποτέ η μόνη ένδειξη.
- Αν η εφαρμογή ανάγνωσης δεν εκτελεί JavaScript: λίστα, περιγραφή και στατικές όψεις.

## Βήματα

1. **Στο 3ds Max:** δώσε ονόματα στα αντικείμενα (π.χ. `sigma_CC`, `pi_1_lobe_upper`, `plane_1`) και ένα υλικό ανά ρόλο. Κάνε απευθείας εξαγωγή σε GLB, χωρίς ενδιάμεσο VRML. Για παλιά αρχεία .3ds ή .WRL υπάρχει ο μετατροπέας `02_tools/convert_3dsmax` (δίνει ονόματα και καθαρίζει τους λοβούς)· οι γωνίες και τα ονόματα θέλουν πάντα έλεγχο από τον εκπαιδευτικό.
2. **Έλεγχος:** άνοιξε το GLB στο `GLB-Lab-0.1.html`. Δες ποια τμήματα δεν έχουν όνομα και ποια χρώματα μπερδεύονται.
3. **Σημασιολογικός χάρτης:** πρόσθεσε μια σελίδα στο `configs.py`, όπως οι πέντε που υπάρχουν. Για κάθε τμήμα δίνεις όνομα, περιγραφή, ποια αντικείμενα του GLB του ανήκουν (`match`) και χρώματα (`safe` για σκούρο και ανοιχτό θέμα). Μπορείς να ζητήσεις από AI να τον γράψει, με το prompt παρακάτω.
4. **Παραγωγή:** `python3 gen.py web έξοδος/` για ιστοσελίδα ή `python3 gen.py epub …` και `python3 gen.py fallback …` για EPUB.
5. **Επαλήθευση:** τρέξε τον έλεγχο παλέτας (`verify_pal.js`): κάθε ρόλος να έχει αντίθεση τουλάχιστον 3:1. Μετά κάνε τις εργασίες Τ1–Τ7 του πρωτοκόλλου. Οι περιγραφές θέλουν **επιστημονικό έλεγχο** από τον εκπαιδευτικό.

## Prompt για τον σημασιολογικό χάρτη

```text
Σου δίνω τη λίστα των αντικειμένων ενός GLB (όνομα, χρώμα υλικού, διαστάσεις) από το GLB Lab, και τι δείχνει το μοντέλο:
«…». Γράψε μια νέα εγγραφή για το configs.py, όπως η εγγραφή "07-complete-sigma-pi-explorer":
- groups: για κάθε ρόλο id, label, description (1–2 προτάσεις, ορολογία σχολικού βιβλίου Χημείας Γ΄ Λυκείου),
  match (ονόματα αντικειμένων), orig (αρχικό χρώμα), safe (από την παλέτα SIG, HYB, PI1, PI2, PL1, PL2, PL3, HTR, NEU, AXM),
  και για διαφανή επίπεδα outline=True και pattern ("stripes" ή "dots") όπου δύο επίπεδα θα ξεχώριζαν μόνο στο χρώμα.
- views: label και note για πλάγια όψη, όψη κατά μήκος του άξονα και όψη από πάνω, με ό,τι φαίνεται πραγματικά σε καθεμία.
- summary: 2–3 προτάσεις για το μόριο.
Μην επινοήσεις τμήματα που δεν υπάρχουν στη λίστα· σημείωσε όσα δεν μπορείς να αναγνωρίσεις.
```
