English supplementary review package · 2 November 2026

Accessibility auditing and remediation for interactive 3D publications

Georgios Korakakis, Konstadina Dalacosta and Maria Vlassi

This package provides an English educational derivative of the Greek materials examined in the study. The original molecular models were authored by Georgios Korakakis in Autodesk 3ds Max. The authors personally checked the materials; the stored AI-operated technical runs are a separate source of evidence. English translations and new verification records are identified below.

The five interactive pages

The pages contain translated component names, scientific descriptions, view descriptions, keyboard instructions, live announcements and static image alternatives. Each page is self-contained.

  1. Ethyne structure and the ball-and-stick representation
  2. sp hybrid orbitals and the two π bonds
  3. Molecular axis and symmetry planes
  4. Exploring σ and π bonds
  5. Comparing ethane, ethene and ethyne

Focus the model and use arrow keys for rotation, +/− for zoom, 1/2/3 for preset views, 0 to reset and D for the view description. Text descriptions and static views are also available within each page.

The English EPUB

  • Download the English EPUB
  • Open Edu Ebook Reader and choose the EPUB file. Select English in the reader’s language control. The reader’s bundled demonstration is the English derivative.

The EPUB contains 18 sections, including five interactive pages, with five separate linked XHTML alternatives and 21 static images. All chapter text, navigation, quiz content, feedback, SVG instructional text and model announcements have English versions. The two retained videos have no audio tracks; their scientific labels use standard orbital notation, and English text alternatives accompany them.

The reader PWA needs HTTPS or a local HTTP server. The standalone pages above can be opened separately. An EPUB-validity result is not a certification of accessibility.
