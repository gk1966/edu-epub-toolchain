# Edu Ebook Reader in the English review package

The reader has an English/Greek interface. Select English in its language control. The bundled `demo-sp-hybridization-v3.0.epub` is the English translated module in this package.

Serve this supplementary folder using a local static HTTP server and open `tools/reader/index.html`, then choose File and select the EPUB. A PWA requires HTTPS or localhost; the five standalone HTML pages in `pages/` are self-contained alternatives.

Reader version: 1.1.0. Original reader software is retained. The demonstration EPUB has been replaced by the separately identified English derivative. Original test records refer to Greek materials and are stored in `original_records/`.
